CREATE TABLE fact_orders (

  order_sk BIGINT NOT NULL,

  customer_address TEXT,

  product_name VARCHAR(100),
  price DECIMAL(10,2),

  order_date DATE,

  -- Fact Measures
  quantity INT,
  line_total DECIMAL(12,2) -- Derived: quantity * price

### Summary of Changes:
- **Schema Type**: Star schema with a single fact table and no separate dimension tables.
- **Join Reduction**: Eliminates 3 joins (to customers, orders, products) for most analytical queries.
- **Redundancy Introduced**: Dimensional attributes (names, addresses, etc.) are duplicated per fact row.
- **Performance Gains**: Faster aggregations, easier filtering, better compatibility with BI tools.
- **Maintenance**: Batch ETL processes should populate this schema; not intended for OLTP updates.
