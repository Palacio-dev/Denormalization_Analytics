### SQL DDL Creation Script

The following script creates the denormalized table. It flattens the schema into a single table (`denormalized_sales`), which is optimized for fast read-heavy analytical queries.

```sql
-- Drop the table if it already exists to ensure a clean slate
DROP TABLE IF EXISTS denormalized_sales;

-- Create the denormalized "One Big Table" for analytics
CREATE TABLE denormalized_sales (
    -- Surrogate/Primary Key for the analytical table
    sales_record_id SERIAL PRIMARY KEY,
    
    -- Order Details (Base Grain)
    order_detail_id INT NOT NULL,
    quantity INT NOT NULL,
    
    -- Order Information
    order_id INT NOT NULL,
    order_date DATE,
    
    -- Customer Information
    customer_id INT NOT NULL,
    customer_name VARCHAR(100),
    customer_email VARCHAR(100),
    customer_address TEXT,
    
    -- Product Information
    product_id INT NOT NULL,
    product_name VARCHAR(100),
    price DECIMAL(10,2),
    
    -- Derived/Pre-calculated Metrics
    total_amount DECIMAL(12,2) -- Calculated as (quantity * price) during ETL/ELT
);

-- Optional: Create indexes on commonly filtered/grouped columns for further OLAP optimization
CREATE INDEX idx_denorm_order_date ON denormalized_sales(order_date);
CREATE INDEX idx_denorm_customer_id ON denormalized_sales(customer_id);
CREATE INDEX idx_denorm_product_id ON denormalized_sales(product_id);
```
